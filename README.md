## PeerSphere
### Overview
PeerSphere is an online platform designed to help students find study groups based on their academic modules. This enables users to connect with peers, collaborate on academic projects, and improve their learning experience.
#### Key Features 
**Module-Based Study Groups:**  Find and join study groups based on modules which have been saved to your preferences
**Secure Authentication:** Uses Firebase Authentication for seamless and secure user login
**Real-time Communication:** Chat instantly with study group members via WebSockets
**Robust Backend:** Powered by a MySQL database for efficient data management, with Docker integration ensuring consistent deployment
**Continuous Integration:** A CI Pipeline automates testing and deployment, maintaining high code quality
**Modular Architecture:** The backend follows a scalable design pattern for efficient file management and maintainability.
